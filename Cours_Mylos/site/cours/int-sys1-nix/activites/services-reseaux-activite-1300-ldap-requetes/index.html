Services réseaux - Activité 1300, Requêtes LDAP

dominique huguenin (dominique.huguenin@rpn.ch) - 19.08.2020 11:22
  • A faire
  • Exemple
  • Références

A faire

Créer les requêtes suivantes:

  • Rechercher dans l’Active Directory (ldap.s2.rpn.ch), toutes les personnes faisant parties de votre classes.

  • Rechercher dans l’Active Directory, la listes des personnes pouvant utiliser les wiki (CN=GGS_S2M_Projets_Etudiants,OU=WEB,OU=ARGroupesGlobaux,DC=s2,DC=rpn,DC=ch)

    Aide - Dans active Directory, il est possible de créer des groupes imbriqués ou nested group .

Ces requêtes utilisent la commande ldapsearch.

Exemple

La requête ci-dessous:

huguenindo@ubuntu-usb-dhu:~$ ldapsearch -H ldap://ldap.s2.rpn.ch\
              -D "CN=Huguenin Dominique (DHU),OU=Enseignants,OU=TI,OU=CPNE,OU=Utilisateurs,DC=s2,DC=rpn,DC=ch"\
              -W\
              -b OU=CPNE,OU=Utilisateurs,DC=s2,DC=rpn,DC=ch\
              "(cn=*Huguenin*)"\
              dn
