A faire

Créer des scripts permettant de créer et supprimer un utilisateur dans le domaine antiterre.lan.

Le script doit être exécuté par le root (sudo)

Utilisation du script de création

galatograd:$ sudo antiterre-adduser -u utilisateur -p mot-de-passe

Ce script crée l’utilisateur, un groupe de même nom dans l’annuaire ldap, un principale dans le service kerberos et un dossier personnel /home/utilisateur dans le serveur de fichier.

Afficher l’aide de la commande

galatograd:$ sudo antiterre-adduser -h

usage: antiterre-adduser -u | --username <username> -p | --password <password>

Création d'un utilisateur dans l'infrastructure antiterre

usage: antiterre-adduser -h | --help

affiche l'aide

Utilisation du script de suppression

galatograd:$ sudo antiterre-deluser -u utilisateur

Ce script supprime l’utilisateur, son groupe et son dossier personnel.

Afficher l’aide de la commande

galatograd:$ sudo antiterre-deluser -h


usage: antiterre-deluser -u | --username <username> 

Suppression d'un utilisateur dans l'infrastructure antiterre

usage: antiterre-deluser -h | --help

affiche l'aide
