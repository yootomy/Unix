  • Références

A faire

Sur la machine atomium, installer et configurer le service de supervision Nagios.

Le service nagios doit

  • alerter l’administrateur par mail en cas de dérangement.

  • surveiller la présences des services ssh, DHCP (à vérifier si le service se trouve sur une autre machine), DNS, Kerberos, ldap

  • Écrire une marche à suivre décrivant les étapes de l’installation, les configurations et les tests de fonctionnement. Citer en référence les liens internet utilisés.

Installation depuis le dépôt

$ sudo apt-get install nagios3
