Objectifs

  • Construire un script

Description du problème

Nous aimerions pouvoir simplement télécharger une page du support de cours avec toutes les pages référencées par celle-ci. Le but de ce script est de pouvoir consulter hors ligne ces pages.

L’interface en ligne de commandes doit être simple et facile à utiliser. L’utilisateur doit saisir le minimum d’information.

Marche à suivre

  1. Définir les entrées et les sorties de ce script
    • Livrable: script affichant l’usage avec le paramètre –help
    • Livrable: une exemple de sortie
  2. Définir les moyens de vérification de son bon fonctionnement
    • Livrable: Les commandes de test avec les résultats attendus
  3. Réaliser le script.
    • Livrable: Le script fonctionnel avec le code suivant le convention usuel.
  • Le travail peut être fait par groupe de deux maximum.
  • La réalisation fera l’objet une présentation devant la classe.
