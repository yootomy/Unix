KVM - Cloner dans une LV

  1. Créer un machine virtuelle avec KVM en utilisant comme stockage un volume virtuel lvm (LV) de 4G.
    1. copier le contenu du fichier contenant d’un disque virtuelle dans un volume logique lvm.
    2. Créer la machine virtuelle.
                       cloner
                      -------->
vm1                            vm3
 +-description matériel  -->   +-description matériel
 `-stockage                     `-stockage
    `-fichier            -->      `-volume logique (LV) (/dev/vg/kvm-vm3)

KVM - Étendre la taille du disque d’une vm utilisant lvm

  1. Étendre la taille du disque de 2G.
.---------------------------------.
| LV - /dev/vg/vm4     6G         | Hote
+---------------------------------+
| /dev/sda   6GB                  | disque VM
+------------+--------------------+
| /dev/sda1  |/dev/sda2           | partition
| primaire   |etendue    5.5G     |
| 512M       +--------------------+
|            |/dev/sda5           | 
|            |logique    5.5G     |
|            +--------------------+
|            | PV                 | LVM
|            +--------------------+
|            | VG  vmLvm1-vg      | VG
|            +----------+---------+
|            | LV root  |LV swap_1|
+------------+----------+---------+
| fat        |ext4      | swap    | système de fichiers
+------------+----------+---------+
| /boot/efi  |/         | swap    |
`------------+----------+---------'

.---------------------------------.-------------.
| LV - /dev/vg/vm4     6G           +2G         | Hote
+---------------------------------+-------------+
| /dev/sda   8GB                                | disque VM
+------------+--------------------+-------------+
| /dev/sda1  |/dev/sda2           | /dev/sda3   |  partition
| primaire   |etendue    5.5G     | primaire 2G |
| 512M       +--------------------+             |
|            |/dev/sda5           |             |
|            |logique    5.5G     |             |
|            +--------------------+-------------+
|            | PV                 | PV          |  LVM
|            +--------------------+-------------+
|            | VG  vgvmlvm3                     |  VG
|            +------------------------+---------+
|            | LV root                |LV swap_1|
+------------+------------------------+---------+
| fat        |ext4                    | swap    |  système de fichiers
+------------+------------------------+---------+
| /boot/efi  |/                       | swap    |
`------------+------------------------+---------'

Création d’un nouveau volume logique

             .---------------------------------..---------------------------------.
Hote         | LV - /dev/vg/vm4                || fichier - ~/tmp/pool/vol1.img   | 
             +---------------------------------++---------------------------------+
Guest        | /dev/vda                        || /dev/vdb                        | 
             +---------------------------------++---------------------------------+
partition    | /dev/vda1                       || /dev/vdb1                       | 
             | primaire                        || primaire                        |
             +---------------------------------++---------------------------------+
LVM          | PV                              || PV                              | 
             +---------------------------------++---------------------------------+
             | VG  vmLvm1-vg                                                      | 
             +-----------------------+---------+----------------------------------'
             | LV root               |LV swap_1|  LV data |                       |
             +-----------------------+---------+----------+-----------------------'
             |  ext4                 | swap    | ext4     |
             +-----------------------+---------+----------'
             | /                     | swap    |  /mnt    |
             `-----------------------+---------+----------'

Dans le machine vmLvm3,

  • Créer un nouveau volume logique data
  • Formater ce volume logique en ext4
  • Monter ce stockage en /mnt
  • Faire en sorte que le montage soit permanent.
