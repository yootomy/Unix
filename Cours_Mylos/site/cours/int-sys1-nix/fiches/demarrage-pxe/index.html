Installation PC MC0-0315-nn avec PXE

Accès au menu pour choisir le périphérique de démarrage.

Choix du périphérique de démarrage

  • Pressez F8 pour sélectionner le menu permettant de choisir le périphérique de démarrage.
  • Choisir IBA GE Slot pour démarrer sur le réseau

Choix du type d’installation

Dans le menu PXE Menu, sélectionner la 2ème option Installation de Debian 12 64-bit

La première option Installation automatique de Debian 12 64-bit sur nodeX permet l’installation d’un serveur de base sans intervention.

Choix de la carte réseau

Le PC MC0-0315-nn possède deux cartes réseaux.

  • la première est sur la carte mère enp3s0, Realtek
  • la deuxième est une carte d’extension enp5s1, Intel…
  • Choisir la carte enp5s1, Intel…
