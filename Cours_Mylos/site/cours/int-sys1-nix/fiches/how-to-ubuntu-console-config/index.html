configuration de la taille de caractère de la console

La commande ci-dessous permet de reconfigurer la console (CTRL-ALT-F1…F6)

$ sudo dpkg-reconfigure console-setup

Pour avoir une grande font utiliser “Terminus” 32x16

Bips de la console

  • stopper les bips d’erreurs

    setterm -blength 0
