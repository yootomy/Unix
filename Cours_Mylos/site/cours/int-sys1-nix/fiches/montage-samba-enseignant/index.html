Installation des outils

sudo apt-get install smbclient cifs-utils

Ajouter l’autorisation d’utiliser mount et umount à tous les utilisateurs

problème voir HugueninWeblog_blogentry_260914_1

ubuntu@lozan:~$ sudo chmod +s $(which mount.cifs)
ubuntu@lozan:~$ sudo chmod +s $(which umount.cifs)

ubuntu@lozan:~$ sudo visudo
%#10004 ALL=(ALL) NOPASSWD: /bin/mount,/bin/umount,/sbin/mount.cifs,/sbin/umount.cifs
%mount ALL=(ALL) NOPASSWD: /bin/mount,/bin/umount,/sbin/mount.cifs,/sbin/umount.cifs

Les utilisateurs du groupe mount et du groupe avec le gid 10004 peuvent effectuer un montage.

$ sudo mount ....

Montage Samba

Dossier personnel, Enseignant

  • Création du point de montage
huguenindo@lozan:~$ mkdir S2MesDocuments
  • Montage du partage personnel
huguenindo@lozan:~$ sudo mount -t cifs //s2msrvadmll.s2.rpn.ch/et/Pers/Profs/Info/HugueninDo ~/S2MesDocuments -o username=huguenindo
Password: 
Password for huguenindo@//s2msrvadmll.s2.rpn.ch/et/Pers/Profs/Info/HugueninDo:
  • vérification
huguenindo@lozan:~$ mount | grep S2MesDocuments
//s2msrvadmll.s2.rpn.ch/et/Pers/Profs/Info/HugueninDo on /home/S2/huguenindo/S2MesDocuments type cifs (rw)
  • Démontage
huguenindo@lozan:~$ sudo umount ~/S2MesDocuments
