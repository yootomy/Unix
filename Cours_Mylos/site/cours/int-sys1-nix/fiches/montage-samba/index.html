Dossier Partages Élèves

  • identifiant de l’utilisateur
huguenindoe@lozan:~$ id
uid=10002(huguenindoe) gid=10000(domain users) groups=10000(domain users),...
  • Création du point de montage
huguenindoe@lozan:~$ mkdir ~/S2PartagesEleves
  • Montage du partage
huguenindoe@lozan:~$ sudo mount -t cifs //s2msrvelell.s2.rpn.ch/Partages/BoitesClasses \
                ~/S2PartagesEleves -o username=huguenindoe,domain=S2,uid=10002,gid=10000
Password for huguenindoe@//s2msrvelell.s2.rpn.ch/Partages/BoitesClasses:  ************

huguenindoe@lozan:~$  mount | grep S2PartagesEleves
