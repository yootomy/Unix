Montage ssh

installation des paquets

sudo apt-get install sshfs

Montage

ubuntu@MC0-0315-00-DHU:~$ man sshfs

SSHFS(1)         User Commands                       SSHFS(1)

NAME
       SSHFS - filesystem client based on ssh

SYNOPSIS
   mounting
       sshfs [user@]host:[dir] mountpoint [options]

   unmounting
       fusermount -u mountpoint

$ mkdir lozan 
$ sshfs huguenindo@lozan.labo.dhu:/home/S2/huguenindo ~/lozan

ou

sudo mount -t fuse sshfs#huguenindo@lozan.labo.dhu:/home/S2/huguenindo \
~/lozan

On vérifie en faisant:

$ mount

huguenindo@lozan.labo.dhu:/home/S2/huguenindo on /home/ubuntu/lozan \
 type fuse.sshfs (rw,nosuid,nodev,max_read=65536,user=ubuntu)

/etc/fstab

  • Dans /etc/fstab, on ajoute:
# <file system> <mount point> <type> <options> <dump> <pass>
...
sshfs#huguenindo@lozan.labo.dhu:/home/S2/huguenindo  /mnt/lozan fuse

Remarque

/!\ le montage est accessible en tant que utilisateur huguenindo

$ ls -ld lozan

drwx------ 1 10250 10005 4096 2010-05-20 12:08 lozan

Démontage

ubuntu@MC0-0315-00-DHU:~$ fusermount -u ~/lozan/

Montage sftp avec Nautilus

  • Dans le champs emplacement, on écrit:
sftp://huguenindo@lozan.labo.dhu/
  • Cela a pour effet d’ajouter un montage dans ~/.gvfs
$ ls -l .gvfs/

total 4
drwx------ 1 ubuntu ubuntu 4096 2010-03-09 10:17 sftp en tant que \
                                               huguenindo sur lozan.labo.dhu
