Configuration du proxy en ligne de commandes

dominique huguenin (dominique.huguenin@rpn.ch) - 11.08.2020 17:15
  • Configuration
  • Références

Configuration

  • Dans le fichier /etc/environment, ajouter:

    export http_proxy="http://157.26.229.80:3128/"
export https_proxy="http://157.26.229.80:3128/"
export ftp_proxy="http://157.26.229.80:3128/"

  • Proxy pour la commande apt-get, ajouter dans le fichier /etc/apt/apt.conf ou dans le fichier /etc/apt/apt.conf.d/90proxy

    Acquire::http::proxy "http://157.26.229.80:3128/";
Acquire::ftp::proxy "http://157.26.229.80:3128/";
Acquire::https::proxy "http://157.26.229.80:3128/";
