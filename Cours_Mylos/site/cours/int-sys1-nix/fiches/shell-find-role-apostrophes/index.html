Shell - Rôle de l'apostrophe dans la commande find

Exemples montrant l'importance de protéger les patterns de recherche par des apostrophes.

Cas 1

Le dossier courant ne contient pas de fichier répondant au pattern recherché

Recherche sans protection

huguenindo@lozan:tmp$ find  /usr/include -name al*.h
/usr/include/c++/4.8/ext/alloc_traits.h
/usr/include/c++/4.8/bits/alloc_traits.h
/usr/include/c++/4.8/bits/algorithmfwd.h
/usr/include/c++/4.8/bits/allocator.h
/usr/include/c++/4.8/parallel/algorithmfwd.h
/usr/include/c++/4.8/parallel/algobase.h
/usr/include/c++/4.8/parallel/algo.h
/usr/include/aliases.h
/usr/include/alloca.h

Recherche avec protection

huguenindo@lozan:tmp$ find  /usr/include -name 'al*.h'
/usr/include/c++/4.8/ext/alloc_traits.h
/usr/include/c++/4.8/bits/alloc_traits.h
/usr/include/c++/4.8/bits/algorithmfwd.h
/usr/include/c++/4.8/bits/allocator.h
/usr/include/c++/4.8/parallel/algorithmfwd.h
/usr/include/c++/4.8/parallel/algobase.h
/usr/include/c++/4.8/parallel/algo.h
/usr/include/aliases.h
/usr/include/alloca.h

Cas 2

Si le dossier local contient une fichier avec le même pattern que la rechercher. Le comportement du find est différent avec ou sans apostrophe.

Création d’un fichier avec le même pattern rechercher

huguenindo@lozan:tmp$ touch ./al12345.h

recherche sans protection

huguenindo@lozan:tmp$ find  /usr/include -name al*.h

La recherche ne trouve aucun fichier.

recherche avec protection

huguenindo@lozan:tmp$ find  /usr/include -name 'al*.h'
/usr/include/c++/4.8/ext/alloc_traits.h
/usr/include/c++/4.8/bits/alloc_traits.h
/usr/include/c++/4.8/bits/algorithmfwd.h
/usr/include/c++/4.8/bits/allocator.h
/usr/include/c++/4.8/parallel/algorithmfwd.h
/usr/include/c++/4.8/parallel/algobase.h
/usr/include/c++/4.8/parallel/algo.h
/usr/include/aliases.h
/usr/include/alloca.h

Cas 3

L’instruction set -x permet d’afficher les substitutions effectués par bash.

Activation de l’affichage des substitutions du bash

huguenindo@lozan:tmp$ set -x

Recherche sans protection

Bash substitue le caractère générique par le nom de fichier trouvé dans le dossier courant. L’instruction find ne reçoit plus le pattern mais le nom du fichier.

huguenindo@lozan:tmp$ find  /usr/include -name al*.h
+ find /usr/include -name al12345.h

Recherche avec protection.

L’instruction find reçoit toujours le pattern.

huguenindo@lozan:tmp$ find  /usr/include -name 'al*.h'
+ find /usr/include -name 'al*.h'
/usr/include/c++/4.8/ext/alloc_traits.h
/usr/include/c++/4.8/bits/alloc_traits.h
/usr/include/c++/4.8/bits/algorithmfwd.h
/usr/include/c++/4.8/bits/allocator.h
/usr/include/c++/4.8/parallel/algorithmfwd.h
/usr/include/c++/4.8/parallel/algobase.h
/usr/include/c++/4.8/parallel/algo.h
/usr/include/aliases.h
/usr/include/alloca.h
