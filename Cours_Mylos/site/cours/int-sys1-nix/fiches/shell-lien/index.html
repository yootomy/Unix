Shell - Lien hardware et symbolique

Exemple d'utilisation des liens hardware et symboliques.

dominique huguenin (dominique.huguenin@rpn.ch) - 11.08.2020 16:27
  • Création d’un fichier vide
  • Création d’un lien symbolique
  • Création d’un lien hardware
  • Modification du fichier
  • Suppression du fichier

Création d’un fichier vide

huguenindo@lozan:tmp$ touch monFichier.txt
huguenindo@lozan:tmp$ ls -l
total 0
-rw------- 1 huguenindo domain users 0 nov 14 08:06 monFichier.txt

Création d’un lien symbolique

huguenindo@lozan:tmp$ ln -s ./monFichier.txt ./monLienSymbolique.txt

huguenindo@lozan:tmp$ ls -l
total 0
-rw------- 1 huguenindo domain users  0 nov 14 08:06 monFichier.txt
lrwxrwxrwx 1 huguenindo domain users 16 nov 14 08:07 monLienSymbolique.txt -> ./monFichier.txt

Création d’un lien hardware

  • Création
huguenindo@lozan:tmp$ ln ./monFichier.txt ./monLienHard.txt
  • Vérification
huguenindo@lozan:tmp$ ls -il
total 0
1643 -rw------- 2 huguenindo domain users 0 nov 14 08:36 monFichier.txt
1643 -rw------- 2 huguenindo domain users 0 nov 14 08:36 monLienHard.txt

-i, –inode afficher le numéro d’index de chaque fichier

Modification du fichier

  • Modification
huguenindo@lozan:tmp$ echo "qwertzuiop" >> ./monFichier.txt
  • Vérification du contenu dans le fichier
huguenindo@lozan:tmp$ cat ./monFichier.txt 
qwertzuiop
  • Vérification du contenu dans le lien hardward
huguenindo@lozan:tmp$ cat ./monLienHard.txt 
qwertzuiop
  • Vérification du contenu dans le lien symbolique
huguenindo@lozan:tmp$ cat ./monLienSymbolique.txt 
qwertzuiop

Suppression du fichier

  • Suppression du fichier
huguenindo@lozan:tmp$ rm ./monFichier.txt

Le lien symbolique est cassé

huguenindo@lozan:tmp$ cat ./monLienSymbolique.txt 
cat: ./monLienSymbolique.txt: Aucun fichier ou dossier de ce type

Le lien hardware existe toujours

huguenindo@lozan:tmp$ cat ./monLienHard.txt 
qwertzuiop
