Ssh - authentification sans saisie de mot de passe

dominique huguenin (dominique.huguenin@rpn.ch) - 19.08.2020 20:06
  • Schéma
  • Créer une paire de clés (clé privé, clé public)
  • Transférer la clé public sur la machine distante
    • Depuis le client
    • Sur la machine distantes
  • Exemple - ouvrir une session ssh sans saisie de mot de passe sur lozan.labo.dhu

  • références

Schéma

.--------.          .-----------------.
| client |=========>| serveurDistant  |
|        |          |
`--------´          `-----------------´

Créer une paire de clés (clé privé, clé public)

user@client:~$ ssh-keygen

.ssh
├── id_rsa        #clé privé, DOIT rester sur le poste client
├── id_rsa.pub    #clé public
├── known_hosts   #liste des clés public des serveurs

Transférer la clé public sur la machine distante

Depuis le client

user@client:~$ ssh-copy-id user@serveurDistant

ou

user@client:~$ ssh-copy-id -i ~/.ssh/id_rsa.pub user@serveurDistant

Sur la machine distantes

user@client:~$ scp  ~/.ssh/id_rsa.pub user@serveurDistant:/home/user/
user@serveurDistant:~$ cp ~/.ssh/authorized_keys ~/.ssh/authorized_keys_Backup
user@serveurDistant:~$ cat ~/id_rsa.pub >> ~/.ssh/authorized_keys
