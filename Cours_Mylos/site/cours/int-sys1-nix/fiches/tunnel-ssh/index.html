Schéma

.--------.          .---------------------.           .-----------------.
|       2222                                          22
| client |=========>| serveurTunnel       |==========>| serveurDistant  |
|        |          |                     |           |                 |
`--------´          `---------------------´           `-----------------´

Création du tunnel ssh à travers serveurTunnel

Sur le client

client:~$ ssh -N -L2222:serveurDistant:22 user1@serveurTunnel
user1@serveurTunnel's password:
  • -L [[bind_address:]port:host:hostport\Specifies that the given port on the local (client) host is to be forwarded to the given host and port on the remote side.
  • -N\Do not execute a remote command. This is useful for just forwarding ports (protocol version 2 only).

Mise en tâche de fond

CTRL-Z
$ bg
$ jobs
[1]+  En cours d'exécution   ssh -N -L2222:serveurDistant:22 user1@serveurTunnel &

Connexion au serveurdistant ssh via le tunnel ssh

Sur le client

client:~$ ssh user2@localhost -p 2222
...
user2@serveurDistant:~$

Exemple - Accès à l’application web d’administration du switch mc0-0315-sw1.lan2.labo.dhu

.--------.          .---------------------.           .----------------------------.
| client |=========>| brusel.labo.dhu     |==========>| mc0-0315-sw1.lan2.labo.dhu |
|        |          | eth0: 157.26.229.80 |           | 172.16.1.2                 |
|        |          | eth1: 172.16.1.5    |           |                            |
`--------´          `---------------------´           `----------------------------´

Création du tunnel

client:~$ ssh -N -L8443:mc0-0315-sw1.lan2.labo.dhu:443 ubuntu@brusel.labo.dhu

Accès à l’application d’administration

De puis le navigateur internet : https://localhost:8443
