Virtualisation, Activation de l'accès à la console texte de VM KVM

Activation de la commande virsh console

Configuration dans la VM

  • Dans /etc/default/grub de la vm, modifier la ligne comme ci-dessous:
ubuntu@guest:~$ sudo cat /etc/default/grub

...
GRUB_CMDLINE_LINUX_DEFAULT="splash quiet console=ttyS0"
...
  • Régénérer le grub
ubuntu@guest:~$ sudo update-grub
  • Redémarrer la machine virtuelle
ubuntu@guest:~$ sudo init 6

Accès à la console

Accès à la console texte

hote:~$ virsh console test

Escape character is ^]
