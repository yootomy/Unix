Virtualisation - incus + zfs

Virtualisation des conteneurs gérés avec incus utilisant zfs comme volume de stockage.

Installation et configuration de zfs

  • installation de zfs

    $ sudo apt-get install zfsutils-linux

  • Création d’un pool zfs

    $ sudo fdisk -l /dev/sda
Disque /dev/sda : 298.9 GiB, 320072933376 octets, 625142448 secteurs
Disk model: WDC WD3200AAKX-0
Unités : secteur de 1 × 512 = 512 octets
Taille de secteur (logique / physique) : 512 octets / 512 octets
taille d'E/S (minimale / optimale) : 512 octets / 512 octets
Type d'étiquette de disque : dos
Identifiant de disque : 0x204c43a2

Périphérique Amorçage     Début       Fin  Secteurs Taille Id Type
/dev/sda1    *             2048 488282111 488280064 232.9G 8e LVM Linux
/dev/sda2             488282112 625141759 136859648  65.3G 83 Linux

    $ sudo zpool create dpool /dev/sda2

$ sudo zpool list
NAME    SIZE  ALLOC   FREE  CKPOINT  EXPANDSZ   FRAG    CAP  DEDUP    HEALTH  ALTROOT
dpool    65G   112K  65.0G        -         -     0%     0%  1.00x    ONLINE  -

  • Création d’un dataset pour incus dans le pool zfs

    $ sudo zfs create dpool/incus -o mountpoint=none
$ sudo zfs list
NAME                USED  AVAIL     REFER  MOUNTPOINT
dpool              4.34G   220G       24K  /dpool
dpool/incus          24K   220G       24K  none

Installation et configuration de incus

  • installation de incus suivre les instructions du lien

    huguenindo@ubuntu-usb-dhu:~$ sudo su
root@ubuntu-usb-dhu:/home/huguenindo# curl -fsSL https://pkgs.zabbly.com/key.asc | gpg --show-keys --fingerprint
gpg: répertoire « /root/.gnupg » créé
gpg: le trousseau local « /root/.gnupg/pubring.kbx » a été créé
pub   rsa3072 2023-08-23 [SC] [expire : 2025-08-22]
      4EFC 5906 96CB 15B8 7C73  A3AD 82CC 8797 C838 DCFD
uid                      Zabbly Kernel Builds <info@zabbly.com>
sub   rsa3072 2023-08-23 [E] [expire : 2025-08-22]

root@ubuntu-usb-dhu:/home/huguenindo# mkdir -p /etc/apt/keyrings/

root@ubuntu-usb-dhu:/home/huguenindo# curl -fsSL https://pkgs.zabbly.com/key.asc -o /etc/apt/keyrings/zabbly.asc

root@ubuntu-usb-dhu:/home/huguenindo# sh -c 'cat <<EOF > /etc/apt/sources.list.d/zabbly-incus-stable.sources
Enabled: yes
Types: deb
URIs: https://pkgs.zabbly.com/incus/stable
Suites: $(. /etc/os-release && echo ${VERSION_CODENAME})
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/zabbly.asc

EOF'

root@ubuntu-usb-dhu:/home/huguenindo# apt update

root@ubuntu-usb-dhu:/home/huguenindo# apt-get install incus

    root@ubuntu-usb-dhu:/home/huguenindo# adduser huguenindo incus-admin

Création d’un conteneur de test

  • Création du conteneur

    huguenindo@ubuntu-usb-dhu:~$ incus launch images:debian/bookworm/cloud test
Creating test
Starting test                               
huguenindo@ubuntu-usb-dhu:~$ incus list
+------+---------+----------------------+------+-----------+-----------+
| NAME |  STATE  |         IPV4         | IPV6 |   TYPE    | SNAPSHOTS |
+------+---------+----------------------+------+-----------+-----------+
| test | RUNNING | 10.185.16.189 (eth0) |      | CONTAINER | 0         |
+------+---------+----------------------+------+-----------+-----------+

  • accès à la console

    huguenindo@ubuntu-usb-dhu:~$ incus exec test -- su -l debian
debian@test:~$

Finaliser l’installation en installant le service ssh et en configuration les accès avec des clé Ssh - authentification sans saisie de mot de passe
