Création d’une machine virtuelle avec virt-install

virt-install --connect qemu:///system \
   -n vm1 \
   -r 1024 \
   --disk path=./vm1disk.img,format=raw,bus=virtio,size=6 \
   -c ~/iso/debian-13.3.0-amd64-netinst.iso \
   --network network=default,model=virtio \
   --osinfo name=debian11

  • Télécharger l’iso en Obtenir Debian

  • Installation dans une console

    virt-install --connect qemu:///system \
  -n vm1 \
  -r 1024 \
  --disk path=./vm1disk.img,format=raw,bus=virtio,size=6 \
  --location ~/iso/debian-13.3.0-amd64-netinst.iso \
  --network network=default,model=virtio \
  --osinfo name=debian11 \
  --graphics none \
  --console pty,target_type=serial \
  --extra-args "console=ttyS0,115200n8"

accès à la console de la machine virtuelle

virt-viewer -c qemu:///system vm1

Administration d’une machine virtuelle avec virsh

lancer la console d’administration

virsh --connect qemu:///system

Afficher l’aide

virsh # help

Liste de toutes les machines virtuelles (domaines)

virsh # list --all

Démarrer une machine virtuelle

virsh # start vm1
virsh # list

Arrêter une machine virtuelle

virsh # destroy vm1
virsh # list
