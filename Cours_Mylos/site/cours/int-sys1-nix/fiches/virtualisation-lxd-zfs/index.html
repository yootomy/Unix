Virtualisation - lxd + zfs

Virtualisation des conteneurs gérés avec lxd utilisant zfs comme volume de stockage.

  • installation de zfs

    huguenindo@mc0-0315-00:~$ sudo apt-get install zfsutils-linux

  • Création d’un pool zfs

    huguenindo@mc0-0315-00:~$ sudo zfs create dpool/lxd -o mountpoint=none

Création d’un conteneur de test

  • Création du conteneur

    huguenindo@mc0-0315-00:cast$ lxc launch images:debian/bookworm/cloud test -p default
Creating test
Starting test

huguenindo@mc0-0315-00:cast$ lxc list
+-------------+---------+-----------------------+------+-----------+-----------+
|    NAME     |  STATE  |         IPV4          | IPV6 |   TYPE    | SNAPSHOTS |
+-------------+---------+-----------------------+------+-----------+-----------+
| test        | RUNNING | 10.140.247.211 (eth0) |      | CONTAINER | 0         |
+-------------+---------+-----------------------+------+-----------+-----------+

  • accès à la console

    huguenindo@mc0-0315-00:cast$ lxc exec test -- su -l debian
debian@test:~$

Finaliser l’installation en installant le service ssh et en configuration les accès avec des clé Ssh - authentification sans saisie de mot de passe
