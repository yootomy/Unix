Virtualisation - Post-installation d'une VM

dominique huguenin (dominique.huguenin@rpn.ch) - 14.08.2020 10:14
  • Changer les clés du serveur ssh
  • virt-sysprep
    • Références

Après une clone d’une VM, il faut encore dans la nouvelle VM

  1. Renommer la machine dans /etc/hostname
  2. Revoir les résolutions statiques dans /etc/hosts
  3. Revoir si nécessaire la configuration réseau

warning

  1. Redémarrer la machine
  1. Changer les clés du serveur ssh

Changer les clés du serveur ssh

  • Supprimer les clés exitantes
guest:~$ sudo rm -v /etc/ssh/ssh_host_*
