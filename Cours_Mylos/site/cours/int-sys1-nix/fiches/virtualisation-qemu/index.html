Création du disque virtuel

qemu-img create -f raw ./vdisk.img 6G

ls -l

Installation du la machine virtuelle

kvm -hda ./vdisk.img -cdrom ~/iso/debian-12.2.0-amd64-netinst.iso -boot d -m 1024 -k fr-ch

Exécution du la machine virtuelle

kvm -hda ./vdisk.img -m 1024 -k fr-ch -daemonize

Visualisation des processus

ps -ef | grep kvm
