Configuration de la résolution dns pour un domain

Le but de cette fiche est d'ajouter une serveur DNS spécifique pour un domaine particulier accessible via un interface réseau défini. Une application des cette configuration est d'ajouté la résolution du domain *.dhu* lorsque le VPN est activé.

Création d’un script

Cette configuration est éphémère. Elle devra être exécuté à chaque démarrage de vpn. Pour simplifier, le script ci-dessous est crée.

#!/bin/bash
#
# Ajout d'une resolution DNS pour les domaines *dhu
#
# dominique huguenin (dominique.huguenin AT rpn.ch)

INTERFACE=ppp0
DOMAINES='~dhu'
OPTIONS="--set-dns 157.26.229.91 --set-dns 157.26.229.92"

systemd-resolve --interface $INTERFACE --set-domain "$DOMAINES" $OPTIONS
