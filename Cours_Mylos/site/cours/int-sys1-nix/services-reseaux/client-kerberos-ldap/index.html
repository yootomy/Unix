Service réseau - service SSSD pour Kerberos et LDAP

dominique huguenin (dominique.huguenin@rpn.ch) - 19.08.2020 11:26
  • Introduction
  • Installation et configuration
  • Références

Introduction

Configuration d’un poste de travail qui utilisera le service d’annuaire pour trouver les utilisateurs et le service d’authentification Kerberos.

SSSD signifie System Security Services Daemon et il s’agit en fait d’un ensemble de services qui gèrent l’authentification, l’autorisation et les informations sur les utilisateurs et les groupes provenant de diverses sources réseau.

Installation et configuration

  • installation des paquets

    debian@luna:~$ sudo apt install sssd-ldap sssd-krb5 ldap-utils krb5-user

    Information à saisir durant l’installation

    • Default Kerberos version 5 realm: ANTITERRE.LAN
    • Kerberos servers for your realm: kdc1.antiterre.lan
    • Administrative server for your Kerberos realm: kdc1.antiterre.lan

  • vérification

    debian@luna:~$ kinit robick
Password for robick@ANTITERRE.LAN: 

debian@luna:~$ klist
Ticket cache: FILE:/tmp/krb5cc_1000
Default principal: robick@ANTITERRE.LAN

Valid starting     Expires            Service principal
05/26/21 11:57:09  05/26/21 21:57:09  krbtgt/ANTITERRE.LAN@ANTITERRE.LAN
  renew until 05/27/21 11:57:03

  • Configuration SSSD

    debian@luna:~$ sudo vim /etc/sssd/sssd.conf

debian@luna:~$ cat /etc/sssd/sssd.conf
[sssd]
config_file_version = 2
domains = antiterre.lan

[domain/antiterre.lan]
id_provider = ldap
ldap_uri = ldap://ldap1.antiterre.lan
ldap_search_base = dc=antiterre,dc=lan
auth_provider = krb5
krb5_server = kdc1.antiterre.lan
krb5_kpasswd = kdc1.antiterre.lan
krb5_realm = ANTITERRE.LAN
cache_credentials = True

  • ajuster les permissions et redémarrer le service sssd

    debian@luna:~$ sudo chown root:root /etc/sssd/sssd.conf
debian@luna:~$ sudo chmod 0600 /etc/sssd/sssd.conf
debian@luna:~$ sudo systemctl stop sssd
debian@luna:~$ sudo systemctl start sssd

  • Activation de la création automatique du dossier personnel

    debian@luna:~$ sudo pam-auth-update --enable mkhomedir

  • Vérification des accès

    debian@luna:~$ getent passwd vonrathen
vonrathen:*:10001:10001:vonrathen:/home/vonrathen:/bin/bash
