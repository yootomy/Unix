Introduction

Ce document montre comment créer un nouvel utilisateur en reprenant les différentes commandes vues dans les chapitres précédents.

Le principe consiste à :

  1. Créer un utilisateur dans l’annuaire LDAP
  2. Créer un principal Kerberos
  3. Créer un dossier personnel sur le serveur de fichier

Emplacement par défaut du dossier personnel

Pour ne pas faire de confusion entre les utilisateurs locaux et ceux du domaine, le dossier personnel des utilisateurs du domaine sont placé dans le dossier /home/ANTITERRE. La configuration ci-dessous définit l’emplacement par défaut du dossier d’utilisateur.

debian@galatograd:~$ cat /etc/adduser.conf
...
DHOME=/home/ANTITERRE
...

Le dossier personnel des utilisateurs du domaine ANTITERRE seront stocké dans le dossier /home/ANTITERRE.

debian@urbicande:~$ sudo mkdir /home/ANTITERRE
debian@urbicande:~$ ls -l /home
total 8
drwxr-xr-x 4 debian debian 4096 Apr 22 14:44 debian
drwxr-xr-x 5 root   root   4096 Apr 22 14:48 ANTITERRE

Créer un utilisateur dans l’annuaire LDAP

L’utilisateur sera créé sur le serveur d’authentification (galatograd)

Personnalisation de la création d’un utilisateur

  • Création d’un template à partir de l’exemple

    debian@galatograd:~$ sudo cp /usr/share/doc/ldapscripts/examples/ldapadduser.template.sample \
          /etc/ldapscripts/ldapadduser.template

  • Modification du template

    debian@galatograd:~$ sudo vim /etc/ldapscripts/ldapadduser.template 
dn: uid=<user>,<usuffix>,<suffix>
objectClass: inetOrgPerson
objectClass: posixAccount
objectClass: shadowAccount
cn: <user>
uid: <user>
sn: <user>
uidNumber: <uid>
gidNumber: <gid>
homeDirectory: <home>
loginShell: <shell>
gecos: <user>
description: User account

  • Utilisation du template

    debian@galatograd:~$ cat /etc/ldapscripts/ldapscripts.conf
...
# User passwords generation
# Command-line used to generate a password for added users (you may use %u for username here)
# WARNING !!!! This is evaluated, everything specified here will be run !
# Special value "<ask>" will ask for a password interactively
#PASSWORDGEN="cat /dev/random | LC_ALL=C tr -dc 'a-zA-Z0-9' | head -c8"
...
#PASSWORDGEN="pwgen"
#PASSWORDGEN="echo changeme"
#PASSWORDGEN="echo %u"
PASSWORDGEN="<ask>"
...
# You can specify custom LDIF templates here
# Leave empty to use default templates
# See *.template.sample for default templates
#GTEMPLATE="/path/to/ldapaddgroup.template"
#UTEMPLATE="/path/to/ldapadduser.template"
#MTEMPLATE="/path/to/ldapaddmachine.template"
GTEMPLATE=""
UTEMPLATE="/etc/ldapscripts/ldapadduser.template"
MTEMPLATE=""

Création de l’utilisateur

  • Ajout du groupe

    debian@galatograd:~$ sudo ldapaddgroup wappendorf

  • Vérification de l’ajout du groupe

    debian@galatograd:~$ ldapsearch -xLLL -H ldap://ldap1.antiterre.lan \
                    -b ou=groups,dc=antiterre,dc=lan cn=wappendorf

dn: cn=wappendorf,ou=groups,dc=antiterre,dc=lan
objectClass: posixGroup
cn: wappendorf
gidNumber: 10002
description: Group account

  • Ajout de utilisateur

    debian@galatograd:~$ sudo ldapadduser wappendorf  wappendorf

Créer un dossier personnel sur le serveur de fichier

Le dossier de l’utilisateur sera créé sur le serveur de fichier (urbicande)

  • Ajout du dossier personnel

    debian@urbicande:~$ sudo cp -R --copy-contents /etc/skel /home/ANTITERRE/wappendorf

  • Mise à jour des droits

    debian@urbicande:~$ sudo chown -R 10002:10002 /home/ANTITERRE/wappendorf/

  • Vérifier depuis luna en s’identifiant en tant que wappendorf
