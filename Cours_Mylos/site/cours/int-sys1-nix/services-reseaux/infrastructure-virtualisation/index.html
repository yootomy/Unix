Création et configuration du réseau virtuel antibr0

Le réseau virtuel utilisé est un réseau de type NAT sans DHCP. Le service DHCP sera installé sur une des machines virtuelle.

  • Création du réseau

    huguenindo@mc0-0315-00:~$ incus network create antibr0 \
                              ipv4.address=192.168.100.1/24 \
                              ipv4.nat="true" \
                              ipv6.address=none \
                              ipv4.dhcp="false"
Network antibr1 created

  • affichage de la configuration

    huguenindo@mc0-0315-00:~$ incus network show antibr0
config:
  ipv4.address: 192.168.101.1/24
  ipv4.dhcp: "false"
  ipv4.nat: "true"
  ipv6.address: none
description: ""
name: antibr0
type: bridge
used_by: []
managed: true
status: Created
locations:
- none

Création et configuration du profile antiterre

le profile permettra de partager de configuration commune entre les machines

  • création du profile

    huguenindo@mc0-0315-00:~$ incus profile create antiterre                                    
Profile antiterre created

huguenindo@mc0-0315-00:~$ incus profile show antiterre                     
config: {}
description: ""
devices: {}
name: antiterre
used_by: []

  • ajout du stockage au profile

    huguenindo@mc0-0315-00:~$ incus profile device add antiterre root disk path='/' pool=default   
Device root added to antiterre

huguenindo@mc0-0315-00:~$ incus profile show antiterre
config: {}
description: ""
devices:
  root:
    path: /
    pool: default
    type: disk
name: antiterre
used_by: []

  • ajout du réseau

    huguenindo@mc0-0315-00:~$ incus profile device add antiterre eth0 nic nictype=bridged parent=antibr0
Device eth0 added to antiterre

huguenindo@mc0-0315-00:~$ incus profile show antiterre                                         
config: {}
description: ""
devices:
  eth0:
    nictype: bridged
    parent: antibr0
    type: nic
  root:
    path: /
    pool: default
    type: disk
name: antiterre
used_by: []

Création du conteneur blossfeldtstad utilisant le profile antiterre

Starting blossfeldtstad

  • accès à la console

    huguenindo@mc0-0315-00:cast$ incus exec blossfeldtstad -- su -l debian

  • configuration de l’adresse IP ( configuration réseau pour debianSYSTEMD.NETWORK(5) )

    debian@blossfeldtstad:~$ cat /etc/systemd/network/10-cloud-init-eth0.network.network
[Address]
Address=192.168.100.10/24

[Match]
Name=eth0

[Network]
DHCP=no
DNS=192.168.100.1

[Route]
Gateway=192.168.100.1
