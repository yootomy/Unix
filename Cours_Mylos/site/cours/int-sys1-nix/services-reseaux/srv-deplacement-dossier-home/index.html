Service réseau - Déplacement du dossier personnel d'un utilisateur

Cette fiche montre comment changer l'emplacement du dossier personnel d'un utilisateur. Nous avons besoin de faire ces manipulations pour séparer les dossiers personnels des comptes locaux et ceux du domaine.

dominique huguenin (dominique.huguenin@rpn.ch) - 26.03.2024 00:00
  • Changement de l’emplacement du dossier personnel
    • pour un utilisateur local existant
    • pour un utilisateur existant dans LDAP
    • pour les nouveaux utilisateurs locaux
    • pour les nouveaux utilisateurs dans LDAP

Changement de l’emplacement du dossier personnel

pour un utilisateur local existant

  1. Modifier le chemin du dossier personnel dans /etc/passwd 
    $ usermod -m -d /home/ANTITERRE/robick robick
  2. Déplacer le dossier personnel vers le nouvel emplacement (l’option -m déplace le dossier) en local

pour un utilisateur existant dans LDAP

  1. Modifier le chemin du dossier personnel dans ldap. Par exemple avec Apache directory Studio ou une commamde ldapmodify

    ubuntu@galatograd:~$ ldapsearch -xLLL -H ldap://ldap1.antiterre.lan -D cn=admin,dc=antiterre,dc=lan -W -b uid=robick,ou=people,dc=antiterre,dc=lan homeDirectory
Enter LDAP Password: 
dn: uid=robick,ou=people,dc=antiterre,dc=lan
homeDirectory: /home/robick

ubuntu@galatograd:~$ cat changeHome.ldif 
dn: uid=robick,ou=people,dc=antiterre,dc=lan
changetype: modify
replace: homeDirectory
homeDirectory: /home/ANTITERRE/robick

ubuntu@galatograd:~$ ldapmodify -x -H ldap://ldap1.antiterre.lan -D cn=admin,dc=antiterre,dc=lan -W -f changeHome.ldif 
Enter LDAP Password: 
modifying entry "uid=robick,ou=people,dc=antiterre,dc=lan"

ubuntu@galatograd:~$ ldapsearch -xLLL -H ldap://ldap1.antiterre.lan -D cn=admin,dc=antiterre,dc=lan  -W -b uid=robick,ou=people,dc=antiterre,dc=lan homeDirectory
Enter LDAP Password: 
dn: uid=robick,ou=people,dc=antiterre,dc=lan
homeDirectory: /home/ANTITERRE/robick

  2. Déplacer le dossier personnel vers le nouvel emplacement en local ou sur le serveur de fichier, si le dossier se trouve de le serveur de fichier

pour les nouveaux utilisateurs locaux

  1. Spécifier le chemin du dossier personnel dans la commande à la création de l’utilisateur

    $ adduser --home /home/ANTITERRE/pier pier

  2. En changeant les paramètres par défaut

    • Fichier de configuration pour adduser et addgroup 
      $ cat /etc/adduser.conf
...
DHOME=/home/ANTITERRE
...
    • Fichier de configuration pour useradd et groupadd 
      $ cat /etc/default/useradd
...
HOME=/home/ANTITERRE
...

pour les nouveaux utilisateurs dans LDAP

La commande ldapadduser utilise le chemin du dossier personnel qui est défini dans le fichier /etc/adduser.conf de la machine local. Donc il faut configurer ce fichier sur galatograd.

ubuntu@galatograd:~$ cat /etc/adduser.conf
...
DHOME=/home/ANTITERRE
...
