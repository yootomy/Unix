Introduction

Dynamic Host Configuration Protocol (DHCP) est un terme anglais désignant un protocole réseau dont le rôle est d’assurer la configuration automatique des paramètres IP d’une station, notamment en lui affectant automatiquement une adresse IP et un masque de sous-réseau. DHCP peut aussi configurer l’adresse de la passerelle par défaut, des serveurs de noms DNS et des serveurs de noms NBNS (connus sous le nom de serveurs WINS sur les réseaux de la société Microsoft).

Le protocole DHCP fait partie de la couche 7 (Application) du modèle OSI.

Installation et configuration du service DHCP

Pour plus de détail voir [[2]].

Installation des paquets

$ sudo apt-get install isc-dhcp-server

Configuration de base

  • Sauvegarde du fichier de configuration original

    $ sudo cp /etc/dhcp/dhcpd.conf /etc/dhcp/dhcpd.conf.ori

  • Éditer la configuration

    $ sudo vim /etc/dhcp/dhcpd.conf

    #
# DHCP antiterre.lan
#
option subnet-mask 255.255.255.0;
option broadcast-address 192.168.100.255;
option routers 192.168.100.1;
option domain-name-servers 192.168.100.1; #ip de la passerelle, valeur temporaire
# option domain-name-servers 192.168.100.10; #id du serveur DNS à installer

option domain-name "antiterre.lan";

default-lease-time 600;
max-lease-time 7200;

authoritative;

subnet 192.168.100.0 netmask 255.255.255.0 {
  range 192.168.100.100 192.168.100.254;
}

Le serveur DHCP distribuera aux clients des adresses IP dans les intervalles 192.168.100.100-192.168.100.254. L’attribution de l’adresse IP se fera pour une durée de 600 secondes si le client ne demande pas une durée différente, la durée maximale du bail étant de 7200 secondes. Le serveur va également ”conseiller” au client d’utiliser le masque de sous-réseau 255.255.255.0, l’adresse de diffusion 192.168.100.255, 192.168.100.1 comme routeur/passerelle et 192.168.100.1 comme serveurs DNS (configuration temporaire, l’adresse du DNS sera par la suite 192.168.100.10). Ce service DHCP fait autorité.

  • vérification de la syntax du fichier dhcpd.conf

    $ dhcpd -t -cf /etc/dhcp/dhcpd.conf
Internet Systems Consortium DHCP Server 4.4.1

All rights reserved.
For info, please visit https://www.isc.org/software/dhcp/

  • Redémarrer le service

    $ sudo systemctl status isc-dhcp-server

INFORMATION sudo journalctl -u isc-dhcp-server permet de consulter les messages du service DHCP.

Auto-configuration du service NTP par le DHCP

L’adresse du serveur NTP peut également être retourner par le serveur DHCP. Pour plus de détail voir [[6]][[7]][[8]]

Configuration du DHCP

Dans /etc/dhcp/dhcpd.conf

...
   # Set the NTP server to be used by the
   # DHCP clients

  option ntp-servers 192.168.100.1;
...

Exemple de configuration

$ cat /etc/dhcp/dhcpd.conf
#
# DHCP 
#
option subnet-mask 255.255.255.0;
option broadcast-address 192.168.100.255;
option routers 192.168.100.1;
option domain-name-servers 192.168.100.10;

option domain-name "antiterre.lan";

default-lease-time 600;
max-lease-time 7200;

authoritative;

subnet 192.168.100.0 netmask 255.255.255.0 {
  range 192.168.100.100 192.168.100.254;
}

host galatograd {
  hardware ethernet 00:16:3e:21:4c:c0;
  fixed-address 192.168.100.20;
}
host urbicande {
  hardware ethernet 00:16:3e:6f:1b:6d;
  fixed-address 192.168.100.30;
}

Correction problème même adresse ip pour les machines luna cavi (netplan)

network:
 version: 2
 renderer: networkd
 ethernets:
   eth0:
     dhcp4: yes
     dhcp-identifier: mac
  • https://netplan.io/reference/

dhcp-identifier (scalar)

(networkd backend only) Sets the source of DHCPv4 client identifier. If mac is specified, the MAC address of the link is used. If this option is omitted, or if duid is specified, networkd will generate an RFC4361-compliant client identifier for the interface by combining the link’s IAID and DUID.
