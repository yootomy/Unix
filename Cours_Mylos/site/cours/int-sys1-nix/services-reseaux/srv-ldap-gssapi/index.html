Service réseau - Service d'annuaire LDAP avec authentification kerberos (GSSAPI)

dominique huguenin (dominique.huguenin@rpn.ch) - 17.03.2022 09:11
  • Introduction
  • Mise en place de l’authentification
  • Références

Introduction

Le but de cette configuration consiste à utiliser kerberos comme méthode d’authentification pour l’accès à l’annaire LDAP.

Mise en place de l’authentification

ATTENTION

A CONFIGURER APRÈS L’UTILISATION DE LDAP PAR KERBEROS

  • Dans kadmin
ubuntu@galatograd:~$ kadmin
Authenticating as principal ubuntu/admin@ANTITERRE.LAN with password.
Password for ubuntu/admin@ANTITERRE.LAN:
  • Création d’un principal pour galatograd.antiterre.lan
kadmin:  addprinc -randkey ldap/galatograd.antiterre.lan@ANTITERRE.LAN
WARNING: no policy specified for ldap/galatograd.antiterre.lan@ANTITERRE.LAN; defaulting to no policy
Principal "ldap/galatograd.antiterre.lan@ANTITERRE.LAN" created.
  • Extraire la clé pour le serveur ldap1.antiterre.lan
kadmin:  ktadd -k galatograd.antiterre.lan.keytab ldap/galatograd.antiterre.lan@ANTITERRE.LAN
Entry for principal ldap/galatograd.antiterre.lan@ANTITERRE.LAN with kvno 2, encryption type aes256-cts-hmac-sha1-96 added to keytab WRFILE:galatograd.antiterre.lan.keytab.
Entry for principal ldap/galatograd.antiterre.lan@ANTITERRE.LAN with kvno 2, encryption type aes128-cts-hmac-sha1-96 added to keytab WRFILE:galatograd.antiterre.lan.keytab.
  • Déplacer la clé dans le dossier /etc/ldap
ubuntu@galatograd:~$ chmod 640 galatograd.antiterre.lan.keytab 
ubuntu@galatograd:~$ sudo chown openldap:openldap galatograd.antiterre.lan.keytab 
ubuntu@galatograd:~$ sudo mv galatograd.antiterre.lan.keytab /etc/ldap/

ubuntu@galatograd:~$ ls -l /etc/ldap/galatograd.antiterre.lan.keytab 
-rw-r----- 1 openldap openldap 190 mai  7 13:40 /etc/ldap/galatograd.antiterre.lan.keytab
  • configuration de openldap pour l’utilisation de la clé, ajouter la ligne ci-dessous dans le fichier /etc/default/slapd
export KRB5_KTNAME=/etc/ldap/galatograd.antiterre.lan.keytab
  • Installation des paquets sasl
ubuntu@galatograd:~$ sudo apt-get install sasl2-bin libsasl2-2 libsasl2-modules libsasl2-modules-gssapi-mit
  • configuration de openldap
ubuntu@galatograd:~$ cat sasl.ldif 
dn: cn=config
add: olcSaslHost
#The FQDN of the Kerberos KDC.
olcSaslHost: kdc1.antiterre.lan
-
add: olcSaslRealm
#The Kerberos realm name
olcSaslRealm: ANTITERRE.LAN
#-
#add: olcSaslSecProps
#disallow insecure authentication mechanisms such as plain passwords
#olcSaslSecProps: noplain,noactive,noanonymous,minssf=56
-
add: olcAuthzRegexp
#by default, the DN of an authorized Kerberos client takes the form
#uid=<Kerberos principal name>,cn=<Kerberos Realm>,cn=GSSAPI,cn=auth
#adjust the following mappings to match the local configuration as necessary
olcAuthzRegexp: {0}"uid=([^/]*),cn=antiterre.lan,cn=GSSAPI,cn=auth" "uid=$1,ou=people,dc=antiterre,dc=lan"
-
add: olcAuthzRegexp
olcAuthzRegexp: {1}"uid=host/([^/]*).antiterre.lan,cn=antiterre.lan,cn=gssapi,cn=auth" "cn=$1,ou=hosts,dc=antiterre,dc=lan"
-
add: olcAuthzRegexp
olcAuthzRegexp: {2}"uid=ldap/admin,cn=antiterre.lan,cn=gssapi,cn=auth" "cn=admin,cn=config"

ubuntu@galatograd:~$ sudo ldapmodify -Y EXTERNAL -H ldapi:/// -f sasl.ldif
