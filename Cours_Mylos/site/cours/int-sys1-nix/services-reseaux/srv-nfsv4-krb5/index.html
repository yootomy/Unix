Configuration du serveur NFSv4

  • Activation du démon svcgssd

    debian@urbicande:~$ sudo vim /etc/default/nfs-kernel-server 

...
# Do you want to start the svcgssd daemon? It is only required for Kerberos
# exports. Valid alternatives are "yes" and "no"; the default is "no".
NEED_SVCGSSD=yes
...

    debian@urbicande:~$ sudo vim /etc/default/nfs-common

# Do you want to start the idmapd daemon? It is only needed for NFSv4.
NEED_IDMAPD=yes

# Do you want to start the gssd daemon? It is required for Kerberos mounts.
NEED_GSSD=yes

    debian@urbicande:~$ sudo vim /etc/idmapd.conf 
[General]

Verbosity = 0
Pipefs-Directory = /run/rpc_pipefs
# set your own domain here, if it differs from FQDN minus hostname
# Domain = localdomain
Domain = antiterre.lan
Local-Realms = ANTITERRE.LAN

[Mapping]

Nobody-User = nobody
Nobody-Group = nogroup

  • Exporter nos dossiers pour les machines connu de kerberos, il faut ajouter les lignes suivantes dans le fichier /etc/exports :

    ...
/home/ANTITERRE   192.168.100.0/24(rw,sync,no_subtree_check,sec=krb5)

Configuration du client NFS

Configuration

robick@cavi:~$ cat /etc/default/nfs-common 
# If you do not set values for the NEED_ options, they will be attempted
# autodetected; this should be sufficient for most people. Valid alternatives
# for the NEED_ options are "yes" and "no".


# Options for rpc.statd.
#   Should rpc.statd listen on a specific port? This is especially useful
#   when you have a port-based firewall. To use a fixed port, set this
#   this variable to a statd argument like: "--port 4000 --outgoing-port 4001".
#   For more information, see rpc.statd(8) or http://wiki.debian.org/SecuringNFS
STATDOPTS=

# Do you want to start the gssd daemon? It is required for Kerberos mounts.
NEED_GSSD="yes"
NEED_IDMAPD="yes"

robick@cavi:~$ cat /etc/idmapd.conf 
[General]

Verbosity = 0
Pipefs-Directory = /run/rpc_pipefs
# set your own domain here, if it differs from FQDN minus hostname
# Domain = localdomain
Domain = antiterre.lan
Local-Realms = ANTITERRE.LAN

[Mapping]

Nobody-User = nobody
Nobody-Group = nogroup
robick@cavi:~$

Montage du système de fichier NFS avec Kerberos

  • Montage

    $ sudo mount -t nfs4 -o sec=krb5 fs.antiterre.lan:/home/ANTITERRE /home/ANTITERRE

  • Vérification

    debian@luna:~$ mount -t nfs4
fs.antiterre.lan:/home/ANTITERRE on /home/ANTITERRE type nfs4 (rw,relatime,sync,vers=4.2,rsize=131072,wsize=131072,namlen=255,hard,proto=tcp,timeo=600,retrans=2,sec=krb5,clientaddr=192.168.100.100,local_lock=none,addr=192.168.100.30)

    debian@luna:~$ cat /etc/fstab 
...
fs.antiterre.lan:/home/ANTITERRE /home/ANTITERRE nfs4 rw,sync,sec=krb5 0 0
