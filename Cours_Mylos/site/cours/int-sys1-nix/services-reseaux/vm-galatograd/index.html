Galatograd. Cité de l’UNION SODROVNO-VOLGACHE, brièvement sa capitale. Caractérisée par des édifices hémisphériques divisés en multiples appartements, avec des fenêtres donnant sur un immense espace intérieur vide qui rappelle de façon frappante le dôme du Panthéon de Rome. Le site semble connecté à l’antichambre des SPHÈRES (EC). Seuls les condamnés errent à l’extérieur des immeubles, et la ville est presque impossible d’accès pour les étrangers (GC).[[1]]

Fonctions

Cette machine virtuel hébergera les services d’authentification.

Création du conteneur galatograd utilisant le profile antiterre

  • Créer le conteneur avec le profile antiterre

    huguenindo@mc0-0315-00:~$ incus launch images:debian/bookworm/cloud galatograd -p antiterre
Creating galatograd
Starting galatograd  

    huguenindo@mc0-0315-00:~$ incus list

Configuration de la machine galatograd

Ensuite, il faut :

  1. configurer l’adresse ip de la machine et les accès ssh.

    L’adresse IP est distribué par le service dhcp.

  2. installation des services pour l’authentification, Service réseau - Service d’authentification
