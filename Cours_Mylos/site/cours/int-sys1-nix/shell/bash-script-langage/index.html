Script simple

Un script doit toujours commencer par une ligne indiquant l’interpréteur à utiliser:

#!/bin/bash

ou

#!/bin/sh

Exemple:

#!/bin/bash

echo "hello, $USER. I wish to list some files of yours"

echo "listing files in the current directory, $PWD"

ls # list files

$USER, $PWD sont des variables.

Variable

  • Définition d’une variable
X="Hello"
X = Hello #erreur
X=Hello world # erreur
X="Hello world" # ok
  • Référer dans un script par :
$X

Apostrophe (’) ou guillemet (")

En principe, les noms de variable sont substituées lors qu’ils se trouvent entre deux guillemets (double quotes) mais pas entre deux apostrophes (single quotes)

#!/bin/bash
echo -n '$USER=' # -n supprime le saut de ligne
echo "$USER"
echo "\$USER=$USER"

La sortie est la suivante ( l’utilisateur est huguenin)

$USER=huguenin
$USER=huguenin

if condition; then
  statement1
  statement2
fi

if condition; then
  statement1
  statement2
else
  statement3
fi

if condition1; then
  statement1
  statement2
elif condition2; then
  statement3
  statement4
elif condition3; then
  statement5
  statement6
fi

Opérateur logique -n

vrai si…

  • la longueur d’opérande est différente de 0.
if [ -n "123" ]
then
  echo vrai
fi

Opérateur logique -z

vrai si…

  • la longueur d’opérande est égale de 0.
if [ -z "" ]
then
  echo vrai
fi

Opérateur logique -d

vrai si…

  • il existe un répertoire avec le nom de l’opérande.
if [ -d "/etc" ]
then
  echo vrai
fi

Opérateur logique -f

vrai si…

  • il existe un fichier avec le nom de l’opérande.
if [ -f "/etc/passwd" ]
then
  echo vrai
fi

Opérateur logique -eq

vrai si…

  • les opérandes sont des entier et qu’ils sont égaux.
if [ 1 -eq 1 ]
then
  echo vrai
fi

Opérateur logique -ne

vrai si…

  • contraire de -eq
if [ 1 -ne 2 ]
then
  echo vrai
fi

Opérateur logique =

vrai si…

  • les opérandes sont des chaînes de caractère et qu’ils sont égaux
if [ "1" = "1" ]
then
  echo vrai
fi

Opérateur logique !=

vrai si…

  • contraire de =
if [ "1" != "2" ]
then
  echo vrai
fi

Opérateur logique -lt

vrai si…

  • operand1 est strictement plus petit que operand2 (les deux opérandes doivent être des entiers)
if [ 1 -lt 2 ]
then
  echo vrai
fi

Opérateur logique -gt

vrai si…

  • operand1 est strictement plus grand que operand2 (les deux opérandes doivent être des entiers)
if [ 2 -gt 1 ]
then
  echo vrai
fi

Opérateur logique -ge

vrai si…

  • operand1 est plus grand ou égale à operand2 (les deux opérandes doivent être des entiers)
if [ 1 -ge 1 ]
then
  echo vrai
fi

Opérateur logique -le

vrai si…

  • operand1 est plus petit ou égale à operand2 (les deux opérandes doivent être des entiers)
if [ 1 -le 1 ]
then
  echo vrai
fi

case

  • synoptique
case word in
  [pattern [| pattern]...) commands ;;]...
esac
  • Exemple
case $variable in
   valeur1) echo "valeur une"
   ;;
   valeur2) echo "valeur deux"
   ;;
   *) echo "valeur par defaut"
   ;;
esac

boucle TANT QUE

exemple 1

#!/bin/bash
X=0
while [ $X -le 20 ]
do
  echo $X
  X=$((X+1))
done

Affiche les nombres de 0 à 20. Tant que la condition est vrai, le script exécute les traitements dans la boucle.

Substitution de commandes

#!/bin/bash
files="$(ls)"
web_files=$(ls ~/tmp)
echo $files
echo $web_files
X=$((3 * 2 + 4)) 
echo $X

Les $( commande ) et `commande` permettent une imbrication des commandes.

Le script affiche les noms des fichiers du répertoire courant et ceux du répertoire public_html et évalue l’expression 3 * 2 + 4
