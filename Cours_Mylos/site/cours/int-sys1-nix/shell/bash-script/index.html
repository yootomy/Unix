Fonctionnement de l’interprétation de commande (fiche BNF Bash)

  • Notation BNF de bash
<instruction> :== <commande> {" " <paramètre>}
<commande> :== <alias> | <commande_interne> | <commande_externe>

<commande_interne> :== <commande_normale> | <commande_algorithmique>
<commande_normale> : ls, cd, ...
<commande_algorithmique> : if, for,...

Ordre de recherche de la commande

Le 1er mot de l’instruction (ou ligne de commande ) est la commande. Cette commande est

  1. une commande bash built-in (man bash retourne les commandes internes) (fiche Bash built-in)
  2. un alias ou fonction
  3. un fichier portant ce nom dans l’arborescence. La variable d’environnement PATH contient la liste de dossier où le fichier doit être rechercher

Pour une commande externe, os démarre un nouveau processus

Alias

  • Alias : nom de substitution d’une commande
alias name='string'

$ cd /usr; ls; cd -

/home/ubuntu

Création d’un alias

  • Création d’un alias
$ alias foo='cd /usr; ls; cd -'

Afficher un alias

  • affiche l’alias foo
$ alias foo
alias foo='cd /usr; ls; cd -'

Exécuter l’alias

Supprimer l’alias

$ unalias foo

$ type foo

type de fichier pour un alias

lister tous les alias

Créer des alias pour monter et démonter ces partages S2

alias s2partageEleves='sudo mount -t cifs //s2msrvelell.s2.rpn.ch/et/Partages ~/S2PartagesEleves -o username=huguenindo,domaine=S2'

Pour rendre persistent les alias, ajouter ces définitions dans le fichier ~/.bashrc ou ~/.bash_aliases

Expansion - Développement

Pour plus de détail voir [2],[4] et [7]

Les expansions sont appliquées à la ligne de commande après qu’elle ait été divisée en mots. Il existe sept types de développements :

  • expansion des accolades
  • développement du tilde
  • remplacement des paramètres et variables
  • substitution de commandes
  • évaluation arithmétique
  • découpage des mots
  • développement des noms de fichiers

[7]

Évaluation arithmétique $((expression))

Découpage des mots - Apostrophe ’

  • Suppression des espaces consécutifs

  • Protection contre la substitution de variable
$ echo The total is $100.00

$ echo 'The total is $100.00'

Script Bash

  • Script bash et [6]
  • Tâches
    1. Écrire le script (fichier textes)
    2. Rendre exécutable chmod +x
    3. Placer le script dans un dossier se trouvant dans le PATH.

Écrire le script (fichier textes)

$ vim ./hello_world

#!/bin/bash
# This is our first script.

echo 'Hello World!'

Rendre exécutable chmod +x

$ chmod +x ./hello_world

Exécution

$ ./hello_world 
Hello World!

Exécution - Erreur

  • Le script n’a pas été trouvé!
$ hello_world 
hello_world : commande introuvable

le script hello_world n’est pas trouvé. La variable PATH ne contient pas le dossier courant.

Exécution - PATH

  • Déplace le script dans un dossier présent dans le PATH du système.
$ mkdir ~/bin
$ mv hello_world ~/bin

$ PATH=~/bin:"${PATH}"

$ echo ${PATH}
/home/ubuntu/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:\
/usr/bin:/sbin:/bin:/usr/games

$ hello_world 
Hello World!

Exemples de script

Beuseu

  • source du script
#!/bin/bash

LIMITE_MAX=10
NUMERO_INTERDIT=7
MOT_MAGIQUE="Beuseu"

if [ "$1" ]; then
  LIMITE_MAX=$1
fi

for VALEUR in $( seq 1 "${LIMITE_MAX}" ); do
  if [ $(( VALEUR % NUMERO_INTERDIT )) -eq 0 ]; then
    echo ${MOT_MAGIQUE}
  else 
    if echo "${VALEUR}" | grep -q ${NUMERO_INTERDIT}; then
      echo "${MOT_MAGIQUE}"
    else
      echo "${VALEUR}"
    fi
  fi
done
