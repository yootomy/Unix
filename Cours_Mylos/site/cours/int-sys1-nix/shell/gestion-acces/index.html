Liste des permission

-rwxrwxr-x 1 dom dom 1306 fév 16  2017 backup

3 classes, utilisateur-groupes-autres (u:user, g:group, o:other)

  • r : lecture
  • w : écriture
  • x : exécution
  • - pas de droits

Permissions Spéciales

tiré du man chmod

Les lettres rwxXst sélectionnent les bits de comportement de fichier des utilisateurs concernés : lecture (r), écriture (w), exécution (ou recherche pour les répertoires) (x), exécution/recherche uniquement si le fichier est un répertoire ou s’il a déjà une autorisation d’exécution pour une des catégories d’utilisateur (X), spécification de l’identifiant du propriétaire ou du groupe propriétaire du fichier lors de l’exécution (s), du drapeau de suppression restreinte ou du bit sticky (t).

Le Sticky bits (t) permet:

  • lorsqu’on l’applique à un exécutable, de le garder en mémoire lors de sa première exécution
  • lorsqu’on l’applique à un répertoire, seul le propriétaire du fichier ou le propriétaire du répertoire a le droit d’effacer les fichiers.

Le SUID, le SGID (s) d’avoir accès aux droits du propriétaire à l’intérieur du programme, pour avoir accès aux fichiers de configuration, par exemple.

Signification des permissions

r w x
fichiers (ordinaire, spéciaux, liens hardware) lecture, cat écriture echo exécution
Dossiers lister, ls ajouter, supprimer touch, rm, mkdir, rmdir,ln traverser, cd
Liens symboliques aucune signification

Permission en octal

Octal Binaire Mode
0 000 ---
1 001 --x
2 010 -w-
3 011 -wx
4 100 r--
5 101 r-x
6 110 rw-
7 111 rwx

Changer les permissions

huguenindo@lozan:~$ chmod u+x,g-w,o= foo.txt 
huguenindo@lozan:~$ ls -l foo.txt 
-rwxr----- 1 huguenindo domain users 0 2010-10-25 16:16 foo.txt

huguenindo@lozan:~$ chmod a=rw foo.txt 
huguenindo@lozan:~$ ls -l foo.txt 
-rw-rw-rw- 1 huguenindo domain users 0 2010-10-25 16:16 foo.txt
Symbole Description ——- Symbole Description
u propriétaire user = la permission devient la nouvelle permission
g groupe propriétaire group + le droit est ajouté à la permission actuel
o le reste du monde other - le droit est retiré à la permission actuel
a tous all, combinaison du u, g, o

Changer les permissions en octal

huguenindo@lozan:~$ chmod 0664 foo.txt 
huguenindo@lozan:~$ ls -l foo.txt 
-rw-rw-r-- 1 huguenindo domain users 0 2010-10-25 16:16 foo.txt

Droits minimums

Quelles sont les droits d’accès minimum à poser pour effectuer les commandes ci-dessous:

.
+-tmp       ---
| `foo.txt  ---
|  
+-tmp2      ---

cp ./tmp/foo.txt ./tmp2

chmod u+x ./tmp
chmod u+r ./tmp/foo.txt
chmod u=wx ./tmp2

.
+-tmp       --x
| `foo.txt  r--
|  
+-tmp2      -wx

.
+-tmp       ---
| `foo.txt  ---
|  
+-tmp2      ---

mv ./tmp/foo.txt ./tmp2

mv == cp + rm

chmod u+wx ./tmp
chmod u+r ./tmp/foo.txt
chmod u=wx ./tmp2

.
+-tmp       -wx
| `foo.txt  r--
|  
+-tmp2      -wx

Changement d’identité

  • s’identifier en tant qu’autre utilisateur
huguenindo@lozan:~$ whoami
huguenindo
huguenindo@lozan:~$ su ubuntu
Password: [mot de passe de l'utilisateur ubuntu]
ubuntu@lozan:/home/S2/huguenindo$ whoami
ubuntu
ubuntu@lozan:/home/S2/huguenindo$ exit
exit
  • exécuter une commande en tant qu’un autre utilisateur. L’utilisateur de départ (ubuntu) doit avoir les droits d’exécuter la commande sudo
ubuntu@lozan:~$ whoami
ubuntu
ubuntu@lozan:~$ sudo -u huguenindo whoami
Password: [mot de passe de l'utilisateur ubuntu]
huguenindo
