Redirection

Dans TLCL voir [1].

 "<"                ">", ">>"   "|"  "<"                ">", ">>"
 stdin   .-----------. stdout        stdin   .-----------. stdout
-------->| commandes |-------->     -------->| commandes |-------->
        0`-----------´1                     0`-----------´1
               |stderr                             |stderr
               |2                                  |2
               |                                   |
               V                                   V
  • “>” - redirige stdout dans le fichier, crée un nouveau fichier.
  • “»” - redirige stdout dans le fichier, ajoute à la fin du fichier existant.
  • “<” - envoie le contenu du ficher dans stdin.
  • “|” - envoie le contenu de stdout dans stdin.

Écrire dans ls.log…

la liste de fichier du dossier /var

huguenindo@lozan:~$ ls -C /var >ls.log

huguenindo@lozan:~$ ls -l ls.log
-rw------- 1 huguenindo domain users 72 2010-10-21 11:39 ls.log

huguenindo@lozan:~$ cat ls.log
backups  cache  crash  lib  local  lock  log  mail  opt  run  spool  tmp

la liste de fichier du dossier /bin/usr qui n’existe pas.

  • Affiche un message d’erreur
huguenindo@lozan:~$ ls -C /bin/usr >ls.log
ls: impossible d'accéder à /bin/usr: Aucun fichier ou dossier de ce type
  • Crée un fichier vide
huguenindo@lozan:~$ ls -l ls.log
-rw------- 1 huguenindo domain users 0 2010-10-21 11:41 ls.log

huguenindo@lozan:~$ cat ls.log

Ajouter dans ls.log…

la liste de fichier du dossier /var

huguenindo@lozan:~$ ls -C /var >> ls.log
huguenindo@lozan:~$ ls -C /var >> ls.log
huguenindo@lozan:~$ ls -C /var >> ls.log
huguenindo@lozan:~$ ls -l ls.log 
-rw------- 1 huguenindo domain users 216 2010-10-21 11:47 ls.log

huguenindo@lozan:~$ cat ls.log
backups  cache	crash  lib  local  lock  log  mail  opt  run  spool  tmp
backups  cache	crash  lib  local  lock  log  mail  opt  run  spool  tmp
backups  cache	crash  lib  local  lock  log  mail  opt  run  spool  tmp

Afficher le nombre de mot du fichier

huguenindo@lozan:~$ wc -w < ls.log
36

Écrire dans wc.log le nombre de mot du fichier

huguenindo@lozan:~$ wc -w < ls.log >wc.log
huguenindo@lozan:~$ cat wc.log
36

Créer un canal (pipe, tuyau)

huguenindo@lozan:~$ ls -C /var | wc -w
36
huguenindo@lozan:~$ ls -C /var | wc -w > wc.log
huguenindo@lozan:~$ cat wc.log
36

Écrire le message d’erreur…

dans le fichier ls-error.log

huguenindo@lozan:~$ ls -C /bin/usr 2>ls-error.log
huguenindo@lozan:~$ ls -l ls-error.log 
-rw------- 1 huguenindo domain users 75 2010-10-21 11:50 ls-error.log

huguenindo@lozan:~$ cat ls-error.log 
ls: impossible d'accéder à /bin/usr: Aucun fichier ou dossier de ce type

dans le même fichier que la sortie standard (stdout)

huguenindo@lozan:~$ ls -C /bin/usr >ls.log 2>&1

ou

huguenindo@lozan:~$ ls -C /bin/usr &>ls.log
