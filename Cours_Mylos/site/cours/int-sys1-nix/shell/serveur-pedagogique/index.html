Localisation du serveur pédagogique

Nom du serveur pédagogique : lozan0.node.dhu

                          +-------+
                          |       |
                          |lozan0 |
                          |       | 
                          +-------+
                              |   lozan0.node.dhu
-------+----------------------+-----------------
       |                                       dhu
   +---+---+
   |       |
   |bastion|
   |       | 
   +---+---+
       |   kobenhavn.s2.rpn.ch 
-------+--------------------------------------- internet

La machine lozan.node.dhu est accessible via la machine bastion kobenhavn.s2.rpn.ch. La machine kobenhavn.s2.rpn.ch est accessible depuis internet.

L’authentification au service ssh de kobenhavn et lozan0 s’effectue uniquement par clés. Ces clés vous seront fournies durant la première leçon de la branche ainsi que le mot de passe pour l’utilisation des clés privées.
