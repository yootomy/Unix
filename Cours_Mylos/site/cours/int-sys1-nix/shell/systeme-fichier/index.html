Nom absolu d’un chemin (Absolute Pathname)

Le nom absolu d’un chemin commence le dossier racine (root), c’est-à-dire par / (barre oblique, slash).

huguenindo@lozan:~$ cd /usr/bin/
huguenindo@lozan:bin$ pwd
/usr/bin

Nom relatif d’un chemin (Relative Pathname)

Le nom relatif d’un chemin commence à partir du dossier courant (working dorectory), c’est-à-dire commence par l’‘‘absence’’ de / (barre oblique, slash) ou par ./

  • Le symbole “..” représente de dossier parent.
  • Le symbole “.” représente de dossier courant.

Exemples

Déplacement avec nom de fichier absolu

huguenindo@lozan:~$ cd /usr/bin/
huguenindo@lozan:bin$ pwd
/usr/bin

Déplacement vers le parent

huguenindo@lozan:bin$ cd ..
huguenindo@lozan:usr$ pwd
/usr

Déplacement vers un dossier contenu dans le dossier courant (nom de fichier relatif)

huguenindo@lozan:usr$ cd ./bin
huguenindo@lozan:bin$ pwd
/usr/bin

Dossier personnel

Le symbole “~” représente un raccourci du chemin vers le dossier personnel de l’utilisateur.

huguenindo@lozan:bin$ cd ~
huguenindo@lozan:~$ pwd
/home/S2/huguenindo

ou

huguenindo@lozan:~$ cd /home/S2/huguenindo
huguenindo@lozan:~$ pwd
/home/S2/huguenindo

Nom d’un fichier (chemin)

Le nom d’un fichier est le chemin pour trouver le ficher avec l’extension (suffix).

huguenindo@lozan:~$ ls /usr/include/aliases.h
/usr/include/aliases.h

  • (d) Répertoires, dossiers

Organisation système de fichiers

voir [1]

 +---------+-----------------+-------------+
 |         | shareable       | unshareable |
 +---------+-----------------+-------------+
 |static   | /usr            | /etc        |
 |         | /opt            | /boot       |
 +---------+-----------------+-------------+
 |variable | /var/mail       | /var/run    |
 |         | /var/spool/news | /var/lock   |
 +---------+-----------------+-------------+
  • “Shareable” files are defined as those that can be stored on one host and used on others.
  • “Unshareable” files are those that are not shareable. For example, the files in user home directories are shareable whereas device lock files are not.
  • “Static” files include binaries, libraries, documentation files and other files that do not change without system administrator intervention.
  • “Variable” files are defined as files that are not static.

Les répertoires les plus fréquemment rencontrés sous les systèmes UNIX sont

  • /bin contient commandes utilisés par tous les utilisateurs (ls, cd ,…)
  • /usr contient les programmes et utilitaires en relation avec l’utilisateur
  • /etc contient les fichiers de configuration et d’administration système
  • /dev contient les fichiers spéciaux
  • /home contient les répertoires personnels des utilisateurs
