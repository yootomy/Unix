Éditeur vi - diagramme d’états

Dans TLCL voir 1.

                       .---------------.
vi <nom_fichier> ----> | mode commande |----.<x> <X>
                       |    (normal)   |<---'
                       `---------------'
                    <i> | ^         ^ |
                    <a> | |    <esc>| |<:>                            
                    <o> | |<esc>    | |                            
                        v |         | v                            
            .---------------.     .---------------.   <w><q> 
            | mode insertion|     | mode complexe |------->
            `---------------'     `---------------'
  • mode commande (normal) - déplacement dans le documents
  • mode insertion - saisie et modification du contenu
  • mode complexe - recherche, remplacement, aide, …

Commandes du mode normal (mode commande)

  • touche ESC pour revenir en mode normal

  • x, X : efface le caractère suivant ou avant le curseur

  • dw : efface le mot

  • dd : efface un ligne

  • yw : copie le mot courant dans le buffer

  • yy : copie la ligne dans le buffer

  • p : copie le buffer à la position courante

  • / : recherche un mot, n suivant N précédent

  • i : mode insertion avant le curseur

  • a : mode insertion après le curseur

  • : passe en mode complexe

Commandes du mode complexe

  • :q! quitter vi sans sauvegarde
  • :w enregistrer le modification dans le fichier
  • :wq enregistrer et quitter
  • :x enregistrer et quitter
  • :help navigation dans l’aide
