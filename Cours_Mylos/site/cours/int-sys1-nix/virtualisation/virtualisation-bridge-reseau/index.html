Utilisation

… Un autre scénario est d’utiliser un pont sur un système avec une seule interface pour autoriser plusieurs machines virtuelles à accéder au réseau extérieur. [[3]]

-------+---------------------------------------------------virbr0 192.168.122.0/24
       |                                    
       |                                    
-------|--+------------------------------------------------lxcbr0 10.1.16.0/24
 virbr0|  |lxcbr0     
 nat .-+--+-. nat       .------.     .------.     
     |      |           |      |     |      |     
     | hôte |           |  C2  |     | vm3  |     
     |      |           |(lxc) |     |(KVM) |     
     `--+---'           `--+---'     `--+---'     
        |eth0              |eth0        |eth0
        |                  |            |
 -------+------------------+------------+---------S2 157.26.229.0/24

Nous aimerions que la machine virtuelle kvm vm3 et le conteneur LXC C2 soient directement connecter sur le réseau de l’école S2.

Test et C2 étant des machines virtuelles tournant dans la machine hôte. Il faut configurer un pont réseau (bridge) sur celle-ci pour permettre aux vm d’être accessible depuis l’extérieur.

Installation et configuration du pont

Installation des paquets sur l’hôte

hôte:~$ sudo apt-get install bridge-utils

Configurer le pont avec netplan

ATTENTION

Configuration à revoir avec netplan

Dans le fichier de configuration de netplan/etc/netplan/01-netcfg.yaml, mettre les configuration ci-dessous:

  • si le pont br0 possède une adresse fixe 192.168.202.xx et partage l’interface réseau physique eth0
network:
  version: 2
  renderer: networkd
  ethernets:
    enp5s1:
      dhcp4: no   
  bridges:
    br0:
      addresses: 
        - 157.26.229.xxx/24
      gateway4: 157.26.229.1
      nameservers:
        addresses: 
          - 157.26.229.91
          - 157.26.229.92
        search: 
          - labo.dhu
      interfaces:
        - enp5s1
  • si le pont br0 reçoit une ip dynamique du DHCP et partage l’interface réseau physique eth0
network:
  version: 2
  renderer: networkd
  ethernets:
    enp5s1:
      dhcp4: no
  bridges:
    br0:
      dhcp4: yes
      interfaces:
        - enp5s1

information

Configuration valable pour les versions précédentes à ubuntu 18.04 Dans le fichier /etc/network/interfaces, mettre les configuration ci-dessous:

  • si le pont br0 possède une adresse fixe 192.168.202.xx et partage l’interface réseau physique eth0
auto br0
iface br0 inet static
       address 192.168.202.xx
       netmask 255.255.255.0
       broadcast 192.168.202.255
       gateway 192.168.202.1
       bridge_ports eth0
  • si le pont br0 reçoit une ip dynamique du DHCP et partage l’interface réseau physique eth0
auto br0
iface br0 inet dhcp
       bridge_ports eth0

Utilisation du pont par les vm

Configuration réseau du conteneur C2

hôte:~$ sudo cat /var/lib/lxc/C2/config

...
# Network configuration
lxc.network.type = veth
lxc.network.flags = up
lxc.network.link = br0
lxc.network.hwaddr = 00:16:3e:12:ea:d3

Configuration réseau de la vm vm3

hôte:~$ virsh dumpxml vm3

<domain type='kvm' id='2'>
  <name>vm3</name>
  ...
  <devices>
  ...

  </devices>
  ...
</domain>
