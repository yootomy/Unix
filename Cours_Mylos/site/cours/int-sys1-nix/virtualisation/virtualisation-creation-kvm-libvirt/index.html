Virtualisation - Création d'une VM KVM avec libvirt

Création d'une VM libvirt+kvm en ligne de commande.

dominique huguenin (dominique.huguenin@rpn.ch) - 15.08.2020 15:14
  • Rappel
  • Création d’une VM KVM avec libvirt

Rappel

information

Une machine virtuelle VM est composé de :

  1. une description de matériel
  2. stockages

Création d’une VM KVM avec libvirt

  • Commande de création de la vm
hote-$ virt-install --connect qemu:///system\
    -n vm2\
    -r 1024\
    --disk path=./vm2disk.img,format=raw,bus=virtio,size=4\
    -c ~/iso/debian-12.9.0-amd64-netinst.iso\
    --network network=default,model=virtio\
    --osinfo name=debian11
  • Liste des vm gérer par libvirt
hote:~$ virsh list --all
 ID    Nom                            État
----------------------------------------------------
 -     vm1                            fermé
 -     vmLvm1                         fermé
