Virtualisation - LXC et LVM

Création d’un conteneur

  • Création du conteneur utilisant le volume logique (lvname) lxc-C1 d’une taille fssize de 1G se trouvant dans le groupe de volume (vgname) vg
# lxc-create -t download -n C1 -B lvm --fssize 1G --vgname vg \
                      --lvname lxc-C1 -- -d ubuntu -r bionic -a amd64
  • Afficher le détail du volume logique /dev/vg/lxc-C1
# lvdisplay /dev/vg/lxc-C1

  • Configuration
# cat /var/lib/lxc/C1/config

# Template used to create this container: /usr/share/lxc/templates/lxc-download
# Parameters passed to the template: -d ubuntu -r bionic -a amd64
# Template script checksum (SHA-1): 273c51343604eb85f7e294c8da0a5eb769d648f3
# For additional config options, please look at lxc.container.conf(5)

# Uncomment the following line to support nesting containers:
#lxc.include = /usr/share/lxc/config/nesting.conf
# (Be aware this has security implications)


# Distribution configuration
lxc.include = /usr/share/lxc/config/common.conf

# For Ubuntu 14.04
lxc.mount.entry = /sys/kernel/debug sys/kernel/debug none bind,optional 0 0
lxc.mount.entry = /sys/kernel/security sys/kernel/security none bind,optional 0 0
lxc.mount.entry = /sys/fs/pstore sys/fs/pstore none bind,optional 0 0
lxc.mount.entry = mqueue dev/mqueue mqueue rw,relatime,create=dir,optional 0 0
lxc.arch = linux64

# Container specific configuration
lxc.rootfs.path = lvm:/dev/vg/lxc-C1
lxc.uts.name = C1

# Network configuration
lxc.net.0.type = veth
lxc.net.0.link = lxcbr0
lxc.net.0.flags = up
lxc.net.0.hwaddr = 00:16:3e:68:a8:3d
