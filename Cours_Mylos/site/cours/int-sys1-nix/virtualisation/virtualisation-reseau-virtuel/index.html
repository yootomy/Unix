Afficher les réseaux virtuels

hote:~$ virsh net-list --all
 Nom                  État      Démarrage automatique Persistent
----------------------------------------------------------
 default              actif      yes           yes

Configuration du réseau virtuel default

dhu@mc0-0315-00-dhu:~$ virsh net-dumpxml default

<network connections='2'>
  <name>default</name>
  <uuid>84606cb8-df10-4929-a526-43db0c5e6cb4</uuid>
  <forward mode='nat'>
    <nat>
      <port start='1024' end='65535'/>
    </nat>
  </forward>
  <bridge name='virbr0' stp='on' delay='0'/>
  <mac address='52:54:00:7b:7a:cc'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
  • name:nom du réseau virtuel
  • forward: réseau natté avec le réeau physique (NAT, network address translation)
  • bridge: nom de périphérique réseau virtuel sur l’hôte
  • mac: mac adresse du routeur virtuel
  • ip: plage ip du réseau
  • dhcp:configuration du dhcp

information

  • Les machines kvm gérées par libvirt utiliseront l’information de la balise name pour configurer le réseau.

Création d’un réseau virtuel isolé sans dhcp

Création d’un réseau virtuel nommé net-isole.

  • Ce réseau est isolé c’est-à-dire qu’il n’est connecté à réseau physique à travers un NAT.
  • Ce réseau ne contient pas de DHCP.
  • La machine hôte est connecté à ce réseau avec l’ip 10.10.10.1

Configuration

dhu@mc0-0315-00-dhu:~$ cat ./net-isole.xml

<network connections='2'>
  <name>net-isole</name>
  <bridge name='virbr10' stp='on' delay='0'/>
  <ip address='10.10.10.1' netmask='255.255.255.0'>
  </ip>
</network>

Création

  • Création
dhu@mc0-0315-00-dhu:VM$ virsh net-define net-isole.xml
Réseau net-isole défini depuis net-isole.xml
  • Visualisation et démarrage du réseau
dhu@mc0-0315-00-dhu:VM$ virsh net-list --all
 Nom                  État      Démarrage automatique Persistent
----------------------------------------------------------
 default              actif      yes           yes
 net-isole            inactif    no            yes

dhu@mc0-0315-00-dhu:VM$ virsh net-start net-isole
Réseau net-isole démarré
