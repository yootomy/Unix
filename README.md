# Cours UNIX

Ce dépôt regroupe les notes et ressources du cours **Systèmes d'exploitation de type Unix**.

## Organisation

- `Leçons/` : dossiers par leçon, avec la date au format `JJ.MM.AAAA`, un `suivi.md` et un `liens.md`.
- `Cours_Mylos/` : copie locale du contenu récupéré depuis Mylos/GitLab pour le cours Unix.
- `Activités/` : notes liées aux activités et exercices.
- `Others/` : anciennes notes ou documents utiles qui ne sont pas classés dans une leçon précise.

## Notes

Les dossiers de configuration locaux comme `.obsidian/`, `.claude/` et `.space/` sont ignorés par Git. Ils peuvent exister sur la machine locale, mais ils ne doivent pas être versionnés dans le dépôt.

Le dépôt sert surtout à garder une copie structurée des supports de cours, des notes personnelles et des ressources utiles pour réviser en bash/Unix.
